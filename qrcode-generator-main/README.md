# SALATECH QR Code Generator

A polished, presentation-ready QR code generator built as a final-year project. It allows users to generate QR codes with custom styling, attachments, and a modern interactive interface.

## Project Overview

This application demonstrates a complete web solution for generating and sharing QR codes with:
- custom colors and dot styles
- optional center logos
- file attachments such as images, audio, video, and PDFs
- real-time preview and export options

## Key Features

- 🎨 Customizable QR styling
- 📁 File attachment support
- 🔐 Secure cloud upload flow
- ⚡ Fast live preview and sharing
- 📱 Responsive, modern UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Cloudinary

## Installation

1. Install dependencies
   ```bash
   npm install
   ```

2. Create a local environment file
   ```bash
   NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_cloud_name
   NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET=your_upload_preset
   ```

3. Start the development server
   ```bash
   npm run dev
   ```
